# Security

## Reporting a problem

Please **don't open a public issue** for a security problem.

Report it privately instead: [Security → Report a vulnerability](https://github.com/amntio/amnt-ui/security/advisories/new).

We reply within 3 working days and tell you when the fix ships.

## What's in scope

- the parts in `ui/`
- the `amnt` command in `cli/`
- the parts file in `public/r/`

## Supported versions

Only the latest version on `main` gets fixes.
