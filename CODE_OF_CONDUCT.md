# Code of Conduct

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be kind and patient. Everyone was new once.
- Talk about the work, not the person.
- No harassment, insults or unwanted attention, here or anywhere you represent this project.

## Reporting

Email **conduct@amnt.io**. Every report is read and kept private.
Maintainers may remove comments, code or people that break these rules.
